# It's bedtime

Victor Ibanez's SAS 1: Self and Society project, floating edition.

This is a static HTML/CSS/JavaScript website. It includes the student's reflections, two interviews, personal and health manifestos, and references. The floating-bed artwork is illustrative.

## GitHub Pages

Website address: https://viccybanes.github.io/bedtime/

Publish from the main branch, repository root. The .nojekyll file serves these files directly. All assets use relative paths so the site works at a project github.io address.

## Editing

Edit index.html for text, style.css for design, script.js for navigation and reading controls, and sky.js for the floating scene. DM Sans is served locally; its license is in fonts/dmsans-OFL.txt.

The site respects reduced-motion preferences, has a Pause motion button, larger text, and a print view.
